# THMR Filter 社区计算节点

为东方音乐筛选工作台提供本地计算资源的 Windows 节点。节点下载获准任务、分析音频并提交建议，社区成果由维护者验收后进入正式目录。

本仓库仅提供程序发行包、使用说明和问题反馈入口；客户端与中央源码保持私有。

## 下载与启动

**当前公开测试版：`0.4.0-beta.4`，Windows x64（Windows 10/11）。**

[下载便携包](https://github.com/AoralsFout/thmr-filter-node/releases/download/v0.4.0-beta.4/thmr-node-0.4.0-beta.4-windows-x64-portable.zip) · [全部发布资产](https://github.com/AoralsFout/thmr-filter-node/releases/tag/v0.4.0-beta.4) · [接入与更新说明](docs/安装与更新.md)

1. 下载 `-portable.zip`，解压到希望保存程序的位置，双击根目录的 `thmr-node.exe`。
2. 在网页选择社区邀请码或可信节点凭证接入，填写维护者提供的中央 HTTPS 地址、节点名称，并明确选择新的空业务数据目录。
3. 社区节点完成音频自检并等待批准，检查本机资源设置后主动开启接单。

无需安装 Git、Node.js 或 Python。基础运行环境、FFmpeg/ffprobe 和 7-Zip 已随便携包提供；程序不迁入用户目录，不自动创建快捷方式或开启开机启动。

**beta.2 改用新的便携布局，不接管 beta.1 或 0.3.x 的安装与配置。** 退出旧节点，保留旧目录，用新包、新空数据目录和新邀请码或凭证重新登记，不要将旧节点身份复制给其他人。本版中央结构为 100、元数据协议为 2。

## 本版变化

修复逐曲回传快照身份、只读目录解包误判和暂停/取消终态回传，降低空间统计开销，并完善 Windows 更新目录占用等待。保留人工审核与未确认 API 费用保护。

beta 更新通道暂维持 0% 灰度，不自动切换已有节点；beta.2 及之后同布局节点请保留原目录，由维护者在停止接单、排空和备份后协调升级。

## 可选模型环境

在「本机设置 → 程序与环境」准备 CPU 或 CUDA 环境，可在线下载，也可导入本次发行的离线资源。资源包含固定 Python、环境依赖和模型权重，校验并通过真实推理检查后才激活，无需自行运行 pip 或转换权重。

- CPU 离线资源为一个 ZIP。
- CUDA 离线资源为 `.zip.001`、`.002`、`.003` 三卷；下载全部分卷放在同一目录，在工作台选择 `.001` 即可，不用自行解压。
- CUDA 需要兼容的 NVIDIA 显卡与驱动；工作台检查驱动，不自动安装或升级驱动。

CPU/CUDA 资源可以分开准备，模型和付费 API 默认关闭。模型适用独立许可，详情见 [第三方组件](THIRD-PARTY.md)。

## 任务、数据与退出

停止接单会等待当前任务完成，立即暂停会请求中断当前工作流。完整关闭请使用网页或托盘的「退出程序」；断网且结果待回传时会说明阻塞原因，可主动选择中断退出。

业务数据保存在首次接入选择的绝对路径；模型环境、资源缓存、工具和日志位于便携程序目录。移动程序前先完整退出，移动后检查模型环境；跨电脑使用按新节点登记。不要公开上传邀请码、节点凭证、配置或完整业务目录。

## 更新与测试范围

便携程序支持固定根公钥校验的 beta 更新通道。程序更新在任务与回传排空后切换，模型环境和业务数据分别保留；旧布局需要重新下载便携包。

本版用于多机测试。单机合成验收不代表第二台实体机器、所有显卡或大规模多机负载已经验证。遇到问题请说明版本、系统、设备和复现步骤，并删除日志中的凭证与私人路径。
